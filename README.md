# A Little Question — Date Invitation

A responsive React + Vite interactive date invitation.

## Features
- Responsive romantic UI
- Playful No button and growing Yes button
- Confetti celebration after Yes
- Follow-up date-planning interaction
- No backend required

## Run locally
Install Node.js (LTS), then from this folder run:

```bash
npm install
npm run dev
```

Open the local URL Vite prints in the terminal.

## Build
```bash
npm run build
```

## Deploy on Vercel (simple option)
1. Push this project to a GitHub repository.
2. Sign in to https://vercel.com and choose **Add New → Project**.
3. Import the repository.
4. Keep the default Vite settings and click **Deploy**.
5. Share the generated public URL.

## Deploy on GitHub Pages
For the simplest path, use Vercel with this Vite project. GitHub Pages also works, but Vite needs a `base` setting matching the repository name and a deployment workflow. See https://vite.dev/guide/static-deploy.html#github-pages.

## Personalize it
Edit `src/main.jsx` to change the text and `src/styles.css` to customize the look.
